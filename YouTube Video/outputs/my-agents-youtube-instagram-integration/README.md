# Интеграция в сайт «Мои агенты»

Дополнение сохраняет все существующие карточки и добавляет четвёртого агента — «Сохранение видео YouTube и Instagram». Пользователь может вместе с видео получить отдельный `.txt` с распознанной речью и временными метками.

Архитектура:

1. Браузер работает только с авторизованным Flask-сайтом на HTTPS.
2. Flask проверяет сессию и CSRF, затем обращается к внутреннему API по `127.0.0.1:8091`.
3. Секретный Bearer-ключ находится только в `/etc/my-agents/youtube-agent.env` на сервере.
4. Внутренний API проверяет URL, квоты и лимиты, запускает `yt-dlp` без cookies и сохраняет файл во временном каталоге.
5. Если включён флажок извлечения текста, локальный `faster-whisper` распознаёт речь на сервере; аудио не отправляется стороннему сервису.
6. Flask потоково передаёт пользователю готовое видео и текст. После готовности пользователь может отправить оба файла в свой уже привязанный основной Telegram-бот.
7. Telegram Bot API принимает файлы до 50 МБ. Интеграция использует защитный предел 49 000 000 байт: для более крупного видео отправляются текст и уведомление, а само видео остаётся доступным на сайте.

Изменяемые файлы сайта: `index.html`, `app.js`, `style.css`, `site_server.py`. Unit-файлы приведены рядом. Ядро сервиса хранится отдельно в каталоге `youtube-video-agent-core`.

Поддерживаются прямые ссылки:

- YouTube `watch`, `youtu.be`, `shorts`, `live`, `embed`;
- Instagram `reel`, `reels`, `p`, `tv`.

Профили, ленты, подборки и плейлисты не принимаются. Instagram может не выдать даже публичную публикацию серверу без входа; сервис не запрашивает cookies или пароль и не пытается обходить это ограничение.

Текст является автоматической расшифровкой: точность зависит от качества звука, языка, фонового шума и количества говорящих.
