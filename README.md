# My Agents

Каждому агенту выделена своя папка: [Hyperliquid](./Hyperliquid/), [Bybit Trader](./Bybit%20Trader/), [Bybit Analyst](./Bybit%20Analyst/) и [YouTube Video](./YouTube%20Video/).

Основной код и общие компоненты сайта находятся в `work/`. Файлы в папках агентов — ссылки на этот код: редактирование любого из них меняет тот же единственный файл. Это сохраняет текущие пути запуска на сервере. Локальные результаты находятся в `outputs/`; эта папка не загружается в GitHub.

Старые пути `Documents/GitHub/my-agents357`, `Documents/Imported-Old-Mac-2026-10-08/Documents/Codex/2026-09-25/my-agents` и путь задачи YouTube оставлены только как ссылки для существующих задач Codex. Вторых копий проектов по этим путям нет.
